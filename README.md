# Cloud Plus Player

Cloud Plus Player é um aplicativo para Android TV que organiza e reproduz conteúdo de um provedor configurado pelo usuário.

## Recursos

- Navegação por TV ao vivo, filmes e séries.
- Página inicial com títulos recentes do catálogo do provedor.
- Favoritos e histórico de reprodução.
- Busca de capas alternativas pelo TMDB quando a imagem do provedor estiver indisponível.

## Integração com o TMDB

A integração consulta informações e imagens de filmes e séries para identificar capas pelo título e, quando disponível, pelo ano. O TMDB fornece os metadados e as imagens; o conteúdo reproduzido vem do provedor configurado pelo usuário.

This product uses the TMDB API but is not endorsed or certified by TMDB.

Saiba mais em [The Movie Database](https://www.themoviedb.org/).
